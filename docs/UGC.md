# UGC 改善ループ

HITBOX SNAPでは、次の導線をひとつの改善ループとして扱います。

1. ユーザーが画像を加工し、PNGを保存・コピー・共有する
2. 投稿文に `#HITBOXSNAP` を付ける
3. トップ画面と編集画面からハッシュタグ投稿を閲覧できる
4. 気づいた改善点を GitHub Issues へ送れる
5. 投稿例とIssueを次のUI・背景・判定精度改善へ反映する

## 実装方針

- 投稿はユーザー操作時だけ開始し、自動投稿しない
- X投稿画面では、ユーザーが保存済みPNGを自分で添付する
- 対応端末では Web Share API でPNGと投稿文を同時に共有する
- モバイルの「写真に保存」はPNG付き共有シートを開く。iOSでは「画像を保存」からカメラロールへ追加する
- Web Share APIが使えない端末ではPNGダウンロードへフォールバックする
- 投稿文は判定タイプ別の個数を自動で含め、作品ごとの差を出す
- サイト内でアカウント・投稿内容・画像を収集しない

## 見直しポイント

- `#HITBOXSNAP` の投稿数と投稿内容
- 背景・判定タイプ・コピーの利用傾向（ユーザーの公開投稿から確認）
- GitHub Issues に届いた再現可能な要望
- 投稿時に迷いやすい箇所や、画像添付まで到達できない導線
