# Hitbox Maker（判定メーカー）

画像に格ゲー風の判定ボックス（攻撃 / 食らい / 投げ / 押し合い）を重ねて描き、PNG として書き出せる Web ツール。画像はブラウザ内だけで処理され、サーバーには送信されない。

## 使い方

- 画像をドラッグ&ドロップ / クリック選択 / ⌘V ペーストで読み込み
- 画像上をドラッグでボックス追加、ボックス内ドラッグで移動、角ハンドルでリサイズ
- キー `1`〜`4` で判定タイプ切替、`Delete` で選択ボックスを削除
- 「PNG書き出し」で元画像の解像度のまま合成画像をダウンロード

## 開発

ビルド不要の静的サイト（`index.html` 1枚）。ローカル確認は:

```bash
python3 -m http.server 8000
```

## デプロイ (Cloudflare Pages)

- ダッシュボードでこのリポジトリを接続し、Build command なし / Output directory `/` で設定
- または `npx wrangler pages deploy .`
